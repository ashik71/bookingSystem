# Archive — the hand-coding era (sessions 001–003)

Before ADR-0004 (2026-10-09), the plan was for the developer to write every line
while an AI taught each topic. These files come from that plan. **They no longer
drive the build.** BMAD epics and the sandbox workflow do.

| File | What it was | Still useful for |
|---|---|---|
| `CURRICULUM.md` | Topic-by-topic teaching order around the focus areas | A checklist of what the architecture and PRs must cover in each focus area |
| `ROADMAP.md` | The original 15-phase learning roadmap (pre-refocus) | Resource links |
| `lessons/phase-1/` | Eight ASP.NET Core Web API lessons with interview question banks | Reviewing agent PRs in depth; interview prep |

Instructions in these files about "the developer writes all code" or "the AI must
not touch `src/`" are **superseded**. Don't follow them.
