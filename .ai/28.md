## Decisions
- Renew every `LeaseSeconds / 3`. A refused renewal cancels the run at once. A renewal that errors is retried every interval/4 and the run is cancelled when `now >= expiresAt - interval`.
- Release uses its own 5 s timeout, never the run's token; failures are logged (EventId 36).
- `Jobs:LeaseSeconds` minimum 3, so tests use 3 s (the plan said 2 s).
- No scan-host change needed: no job is registered in the real app.
